# LotLens

Data + AI tool to decide **where and how to invest in property** in the South West of Western Australia (first region: Margaret River and surrounds, Dunsborough to Augusta): buy land and build, buy established, or renovate.

**Stack:** Python (pipeline, feasibility, forecasting, ML) · SQL (warehouse) · Power BI (market dashboards) · applied AI (planning assistant over WA R-Codes, text-to-SQL analyst, investment memo) · Streamlit (map app).

> Status: phase 1 (vision and data discovery). Indicators are data-driven, not financial advice.
